\section{Research Gaps and Objectives}\label{sec:research-gaps-and-objectives}

Drawing from the literature, we have identified a number of research gaps that this project aims to address.

First, most MSAR UAV/USV work focuses on path planning and communication architectures, giving limited attention to the human factors of supervising drone swarms.
Second, many Digital Twin implementations emphasize modelling and data integration, with less focus on managing workloads with approaches grounded in HCI theory.
Finally, Supervisory-control and MSAR studies rarely combine subjective workload tools like NASA-TLX with objective performance metrics.
This limits our understanding of how interface and autonomy designs impact workload and performance in the MSAR domain.

To address these gaps, this project has the following objectives:

\begin{itemize}
    \item Implement a digital model/shadow of an MSAR drone swarm with layered architecture, suitable for future integration into a full DT system.
    \item Design a workload-aware human-swarm mission-control interface applying HCI principles using aviation-inspired hierarchies and visual design.
    \item Define a metric suite combining subjective workload assessments like NASA-TLX with objective performance metrics to support future human-subject experiments on workload and performance.
\end{itemize}
