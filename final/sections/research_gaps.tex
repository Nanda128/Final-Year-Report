\section{Research Gaps and Objectives}\label{sec:research-gaps-and-objectives}

Drawing from the literature, a number of research gaps were identified that this project aims to address.

First, most maritime search and rescue (MSAR) unmanned aerial vehicle (UAV) and unmanned surface vessel (USV) work focuses on path planning and communication architectures, giving limited attention to the human factors of supervising drone swarms.
Second, many Digital Twin implementations emphasise modelling and data integration, with less focus on managing workloads with approaches grounded in human-computer interaction (HCI) theory.
Finally, Supervisory-control and MSAR studies rarely combine subjective workload tools like the National Aeronautics and Space Administration Task Load Index (NASA-TLX) with objective performance metrics.
This limits the current understanding of how interface and autonomy designs impact workload and performance in the MSAR domain.

To address these gaps, this project has the following objectives:

\begin{itemize}
    \item Implement a digital model/shadow of an MSAR drone swarm with layered architecture, suitable for future integration into a full Digital Twin (DT) system.
    \item Design a workload-aware human-swarm mission-control interface applying HCI principles using aviation-inspired hierarchies and visual design.
    \item Define a metric suite combining subjective workload assessments like NASA-TLX with objective performance metrics to support future human-subject experiments on workload and performance.
\end{itemize}
